# Black Rink artwork

Approved identity portraits, original stone texture, arena and three prologue
illustrations supplied in the user's Arcade Redesign Handoff v3 (September 2026),
from the companion “Plan Mortal Kombat visual refactor” conversation. These are
original generated illustrations, not extracted Mortal Kombat game assets.

Press Start 2P is distributed with its supplied `FONT-LICENSE.txt` (SIL OFL).

The reaction study, composition wireframes and full-body sprite concept sheet
are intentionally not shipped as animation atlases. `arcadeAssets.js` records the
approved portrait fallback explicitly. Future pose artwork must preserve identity,
facing, scale and anchors and must not replace Season 1/2 historical artwork.
