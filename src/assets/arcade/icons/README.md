# Hockey arcade identity

Original SVG artwork authored directly as vector paths and pixel lettering. No game assets or external fonts are embedded.

- `championship-cup.svg`: silver banded Cup with a gold base; header emblem and historical championship honors.
- `current-champion.svg`: red and gold shield, crossed sticks, crown and silver Cup; current-champion badge on standings.
- `in-season-cup-logo.svg`: gold outlined pixel wordmark; Season 3 header logo.
- `public/arcade-favicon.svg`: simplified 32-unit Cup-and-sticks crest for the browser tab.

The original historical season logos remain in use when browsing those seasons.
